bundle exec jekyll serve --livereload -H localhost

bundle exec jekyll serve:  Starts Jekyll server using Bundler to ensure correct versions of gems are used.
--livereload: ensures browser automatically refreshes to show the latest changes.
-H localhost: specifies Jekyll server should bind to the localhost address, meaning it will only be accessible from the local machine.

bundle exec jekyll serve --livereload -H localhost --port 4002 --livereload-port 35731
	if ports 4001 and 35730 already in use

option  --incremental  Speeds up build process by only regenerating the files that have changed since the last build
BUT: It may not detect changes in certain files, such as _config.yml



config.yml			site-wide settings, after initial set-up should 
					rarely need to be updated
_data/authors.yml		not relevant, unless more than one person for website
_data/navigation.yml		to change order etc in top menu bar
_includes/author-profile.html	additional customization after config.yml, in particular, 
				items in sidebar 
_pages/about.md			file for main homepage
_pages/publications.md		file for publications page
_publications			contains .md files linked to from _pages/publications.md

_sass/_sidebar.scss 		for various sidebar settings
_sass/_page.scss			for various page settings
_includes/sidebar.html		for contents of sidebar
